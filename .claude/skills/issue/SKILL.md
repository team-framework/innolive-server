# 이슈 생성

작업을 시작하기 전에 GitHub 이슈를 만들어요. 이슈는 작업을 추적하는 기준점이에요.

## 작업 유형

아래 네 유형 중 하나를 선택해요.

| 유형 | 사용할 때 |
| --- | --- |
| `feat` | 새 기능을 개발할 때 |
| `fix` | 버그를 수정할 때 |
| `chore` | 기타 자잘한 수정이나 설정 변경을 할 때 |
| `refactor` | 동작은 유지하며 코드를 정리할 때 |

## 제목

제목은 한국어로, 아래 형식으로 작성해요.

```text
<type>: <작업 내용>
```

예시:

```text
feat: GitHub 릴리스 다운로드 기능 추가
fix: 로그인 후 화면 전환 오류 수정
chore: 의존성 버전 정리
refactor: 인증 서비스 구조 개선
```

## 담당자

기본 담당자는 이슈를 만든 본인이에요. 다른 사람이 실제 작업을 맡는다면 그 사람을 담당자로 지정해요.

## GitHub 웹에서 만들기

이슈를 만들 때 작업 유형에 맞는 양식을 선택하고, 제목과 담당자를 지정해요.

## GitHub CLI에서 만들기

```bash
gh issue create \
  --title "feat: GitHub 릴리스 다운로드 기능 추가" \
  --label "feat" \
  --assignee "@me" \
  --body ""
```

생성된 이슈 번호를 이후 브랜치와 PR에 사용해요.
