      테스트 계정 없음 관리자 로그인과 별개로, 이 화면의 요청만 이 계정으로 보냅니다.

        인증 v2 (#380)

        왼쪽에서 테스트할 기능을 고르세요.

        이메일 가입·로그인

        새 InnoLive 계정을 만들거나 기존 이메일 계정으로 로그인합니다. 가입은 v2(이름 필수)로 보냅니다. 가입 완료 응답에는 토큰이 없어 로그인을 따로 합니다.

        구글 로그인 v1·v2

        구글 버튼으로 ID 토큰을 받은 뒤 v1·v2를 각각 호출합니다. v1은 처음 보는 구글이면 예전 방식 계정(이메일 계정 없음)을 만들어, 계정 설정·병합 테스트용 계정을 만들 때 씁니다.

        ID 토큰 없음

        계정 설정 (기존 소셜 계정)

        v2 로그인이 password_setup_required를 주면 setup_token(10분)이 저장됩니다. 이메일·비밀번호를 정해 기존 계정에 이메일 계정을 붙입니다.

        setup_token 없음

        로그인 수단 연결·해제

        테스트 계정으로 로그인한 상태에서 씁니다. 구글 연결은 "구글 로그인" 화면에서 받은 ID 토큰을 씁니다. 예전 방식 계정의 구글을 연결하면 병합(merged: true)됩니다.

        애플 (코드 직접 입력)

        웹 테스트 클라이언트는 애플 로그인을 직접 띄울 수 없습니다. 앱에서 받은 authorization_code와 nonce를 붙여 넣어 호출합니다. 코드는 한 번만 쓸 수 있습니다.

        계정 관리 (토큰·탈퇴)

        테스트 계정의 토큰 갱신·로그아웃·탈퇴입니다. 위 계정 카드에 플랜·송출 연결이 함께 보여 병합 결과(플랜 승계, 유튜브·치지직 이동)를 확인할 수 있습니다.

        탈퇴는 되돌릴 수 없습니다. 이메일 계정·연결된 구글·애플·송출 연결이 모두 삭제되고, 애플은 권한도 취소됩니다.

        비밀번호 변경

        로그인 여부와 관계없이 이메일 인증 코드를 거쳐 바꿉니다. 바꾸면 모든 기기에서 로그아웃되고 이 화면의 테스트 계정만 새 토큰으로 로그인됩니다. 없는 이메일이어도 같은 응답이 옵니다(메일은 안 감).

        v1 종료 점검

        v1 경로가 남아 있는지 확인합니다. 빈 요청을 보내 외부(구글·애플) 호출 없이 라우트 존재만 봅니다. 400이면 아직 있음, 404면 제거됨입니다.
